Marée & profondeur de lagune

Le mode Lagune calcule, sur le relief LiDAR réel, quand une lagune se met en eau et avec quelle profondeur selon la marée. Son moteur (relief fin + remplissage hydraulique) est encore hébergé dans LagoonX ; son intégration native à AirSpotX arrive.

Aide

Vent partagé par tous les modes : cadran (glisser) ou saisie ° + force (kt).

Plané : clique pour poser départ puis arrivée (déplaçables). L'empreinte cyan = zone atteignable (surface = finesse prudente, contour = best glide), décalée sous le vent. Verdict ✓/⚠/✕ selon la marge.

Longe : chaque clic pose une corde ; demi-cercle sous le vent = fenêtre de vol. ✎ pour renommer, poignée orange pour régler longueur + vent.
